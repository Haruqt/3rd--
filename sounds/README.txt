These are wired into script.js via SOUND_FILES — rename with care if you swap any out:

button-click.wav   - Start / Continue / Open Letter / Play Again taps
click-1133.wav     - claw control buttons (◀ ▶ DROP)
claw-drop.mp3      - claw lowering
claw-grab.wav      - successful grab
claw-miss.wav      - failed grab
capsule-open.wav   - capsule releasing into the chute
prize-win.wav      - normal prize modal reveal
final-reveal.wav   - final prize cinematic
timeline-click.wav - tapping a memory link in the timeline
claw-move.mp3      - loops while the claw is moving left/right
bg-musix.mp3       - background music loop, starts on START GAME,
                     muted via the speaker icon top-right

If a file is missing, playback just silently fails and the game
continues normally.
